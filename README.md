# Vault personal (monorepo)

Repositorio de bases de conocimiento personales, mantenidas por un LLM
siguiendo el patrón descrito en [este documento](https://github.com/tobi/qmd)
(fuentes crudas inmutables → wiki vivo que el LLM mantiene → esquema de
gobernanza en `CLAUDE.md`).

Cada carpeta de primer nivel es un vault independiente, con su propio
`CLAUDE.md`, catálogo (`index.md`) y bitácora (`log.md`):

- **[`gestion-conocimiento/`](gestion-conocimiento/index.md)** — teorías, frameworks, metodologías, herramientas y autores de gestión del conocimiento.
- **[`profesional/`](profesional/index.md)** — políticas de I+D+i, beneficios tributarios, financiamiento de innovación, valoración de la innovación, procesos de I+D.
- **[`idiomas/`](idiomas/index.md)** — aprendizaje de francés y portugués.
- **[`ia/`](ia/index.md)** — inteligencia artificial: conceptos, modelos, herramientas, papers.

Ver `CLAUDE.md` (raíz) para las reglas de enlazado entre vaults.
